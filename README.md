# ✍️ AIライティングツール

ブログ執筆・メール返信・要約など、よく使うライティング作業をまとめた個人用のAIツールです。
Python + Streamlit + Gemini API で動作します（DB・ログイン不要）。

## 使えるツール

| ツール | 内容 |
|---|---|
| ✍️ ブログ記事作成 | テーマ・読者・キーワード・文字数から記事を執筆 |
| 📧 メール返信 | 受信メール＋伝えたい要点から返信文を作成 |
| ✉️ メール作成 | 用件から新規メールを作成 |
| 📝 要約 | 3行・箇条書き・TL;DR・議事録形式などで要約 |
| 🔍 校正・推敲 | 誤字脱字・文法チェック、修正版と修正点の表 |
| 🔄 リライト・トーン変換 | 丁寧に／カジュアルに／短く／分かりやすく など |
| 🌐 翻訳 | 自然な表現で多言語に翻訳（訳のポイント解説も可） |
| 📱 SNS投稿作成 | X・Instagram・LinkedIn などに合わせて複数案 |
| 💡 タイトル・見出し案 | 記事・動画・メール件名などのタイトル案を大量に |
| 📄 メモ→文章化 | 箇条書きメモを報告書・日報・スピーチ原稿などに |
| 💬 自由指示 | 上記以外の自由なライティング |

共通機能:

- 出力がリアルタイムで表示される（ストリーミング）
- 「もっと短く」「別の案を」などのワンクリック修正と、自由な追加指示での書き直し（過去のバージョンも確認可）
- コピー用テキスト表示・Markdown ダウンロード
- 生成履歴（`data/history.json` に保存）。検索・絞り込み・再編集が可能
- サイドバーでモデルと創造性（temperature）を切り替え

## セットアップ

Python 3.12 以上が必要です（3.9 はサポート終了済みで、依存パッケージのセキュリティ修正が入りません）。

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Gemini APIキーを [Google AI Studio](https://aistudio.google.com/apikey) で取得し、次のどれかで設定します。

1. 環境変数: `export GEMINI_API_KEY=...`
2. `.streamlit/secrets.toml.example` を `.streamlit/secrets.toml` にコピーして記入
3. アプリのサイドバーに直接入力（そのセッションのみ有効）

## 起動

```bash
streamlit run app.py
```

ブラウザで http://localhost:8501 が開きます。

## ツールを追加する

`tools.py` の `TOOLS` リストに `Tool(...)` を1つ追加するだけで、サイドバーとフォームに自動で反映されます。
